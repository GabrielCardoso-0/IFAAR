## Sobre

Repositório colaborativo da turma de **Análise e Desenvolvimento de Sistemas** do **IFFAR - Campus Uruguaiana**.

**Missão:** Coletar, organizar e preservar materiais de estudo, exercícios resolvidos e projetos para beneficiar as atuais e futuras turmas.

**Foco em Java** - Materiais, códigos e projetos desenvolvidos em Java durante o curso.

## 📂 Estrutura

| Pasta | Conteúdo |
|-------|----------|
| `00-ORIENTACOES` | Guias de estudo, dicas de programação, mercado de trabalho |
| `01-1-SEMESTRE` a `06-6-SEMESTRE` | Disciplinas organizadas por semestre |
| `PROJETOS-INTEGRADORES` | Trabalhos da turma |
| `EXERCICIOS-RESOLVIDOS` | Listas de exercícios comentadas |
| `FERRAMENTAS` | Configurações, scripts úteis, extensões |
| `MEMORIAL` | História da turma, fotos, depoimentos |

## 🎯 Como contribuir

1. Faça um fork do repositório
2. Crie uma branch: `git checkout -b minha-contribuicao`
3. Adicione seu conteúdo seguindo os templates da pasta `TEMPLATES`
4. Faça commit: `git commit -m "Adiciona resumo de SQL"`
5. Envie: `git push origin minha-contribuicao`
6. Abra um Pull Request
