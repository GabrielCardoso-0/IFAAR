# Conselhos dos Veteranos para as Futuras Turmas

## Sobre o curso

- **Não subestime a lógica**: É a base de tudo. Domine isso antes de avançar.
- **Programação é prática**: 70% código, 30% teoria.
- **O professor não é inimigo**: Ele está ali para te ajudar. Pergunte!

## Sobre os estudos

- **Crie uma rotina**: 1-2 horas por dia é melhor que 10 horas no fim de semana.
- **Use o repositório**: Todo material que criarem, coloquem aqui.
- **Faça projetos pessoais**: É o que mais ensina.

## Sobre o mercado

- **GitHub é seu currículo**: Mantenha-o organizado desde o primeiro semestre.
- **LinkedIn**: Crie e atualize. Coloque os projetos que fizer.
- **Networking**: Converse com colegas, veteranos, professores.

## Dicas específicas

### Algoritmos
- Pratique no papel primeiro, depois code
- Use o Visual Studio Code desde o início

### Banco de Dados
- Aprenda SQL bem - é usado em todas as empresas
- MySQL é gratuito e ótimo para começar

### Programação
- Escolha uma linguagem e foque nela no primeiro ano
- Aprenda Git junto com programação

## Frase que define o curso

> "Não se aprende programação apenas assistindo. Você aprende programando, errando e corrigindo."
