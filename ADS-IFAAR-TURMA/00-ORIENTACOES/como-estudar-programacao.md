# Como Estudar Programação - Guia da Turma

## 📅 Rotina de estudos recomendada

| Atividade | Frequência | Duração |
|-----------|------------|---------|
| Estudo teórico | Diário | 30min |
| Prática de código | Diário | 1-2 horas |
| Revisão semanal | 1x por semana | 2 horas |

## 🛠️ Ferramentas essenciais

| Ferramenta | Uso | Link |
|------------|-----|------|
| VS Code | Editor de código principal | code.visualstudio.com |
| Git + GitHub | Versionamento e portfólio | github.com |
| Postman/Insomnia | Testar APIs | postman.com |

## 📚 Estratégias que funcionam

✅ **Pomodoro:** 45min foco, 5min pausa
✅ **Ensinar o colega:** Melhor forma de aprender
✅ **Projetos pessoais:** Aplique o que aprendeu
✅ **Documentar aprendizado:** Escreva resumos

## ❌ Erros comuns (evite!)

- Pular a base (lógica e algoritmos)
- Só assistir aula, não praticar
- Não perguntar quando tem dúvida
- Comparar seu progresso com o dos outros

## 🎯 Foco por disciplina

| Disciplina | Foco principal | Ferramentas |
|------------|----------------|-------------|
| Algoritmos | Lógica, fluxogramas, pseudocódigo | Draw.io, papel |
| Programação I | Sintaxe, estruturas básicas | VS Code, Java |
| Banco de Dados | SQL, modelagem | MySQL Workbench, PhpMyAdmin |

## 🎓 Dicas de veteranos

> "A melhor forma de aprender programação é programando. Não espere entender tudo antes de começar."
