# Guia de Contribuição

## Como contribuir com este repositório

### 1. Reportar problemas (Issues)

Abra uma Issue descrevendo:
- **O que não funciona:** Descrição clara do problema
- **Como reproduzir:** Passos para alguém reproduzir
- **Sugestão de correção:** Se tiver uma ideia
